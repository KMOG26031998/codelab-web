1. Extraer el ZIP.
2. Abrir la carpeta CodeLab_Web en Visual Studio Code.
3. Abrir index.html en un navegador (doble clic) o usar la extensión Live Server.
4. Para capturas: página principal, tarjetas de lecciones, reto interactivo, política de privacidad y código HTML.

6. No se incluyen scripts de AdSense ni identificadores inventados. No introducir tarjetas de pago.
